# Mihaku Competitor & Inspiration Research
## "Choose less, do less, feel in control"

Research date: 2026-03-19

## 1. MINIMALIST TASK APPS (Task-Limiting Philosophy)

### 1.1 UndoList — "Do Less, Focus Better"
**Platform:** Android
**URL:** https://www.undolist.app/

**Philosophy:** Intentional productivity through elimination, not accumulation. Inspired by essentialism — "Less, but better." The app celebrates what you *remove* rather than what you complete.

**Home Screen Layout:**
- Three-phase workflow: Capture → Reflect → Focus
- Hard 3-task limit enforced on screen
- "Maybe Later" shelving system visible (guilt-free deferral)
- Deletion rate tracking displayed — users average 73% deletion rate

**Task Input:**
- Capture phase: dump all tasks without judgment
- Reflect phase: 3 guided questions evaluate each task
- Focus phase: keep only 3, delete or defer the rest

**Visual Style:**
- Neumorphic design with soft shadows and subtle depth
- Neutral tones with accent colors for interactive elements
- Clean, spacious typography
- Offline-first, no account required

**What Makes It Feel "Simple" vs "Empty":**
- The reflection questions add meaning to the empty space
- Celebrating deletion (73% rate!) reframes emptiness as accomplishment
- Constraint is the feature, not a limitation

**Mihaku Relevance: HIGH** — UndoList's "Maybe Later" is conceptually identical to mihaku's "let go." The deletion-as-celebration framing is directly aligned. The guided reflection questions mirror mihaku's AI-as-mirror concept.

---

### 1.2 ONLY3 — "Focus on 3 Tasks Daily"
**Platform:** iOS, Android, Web
**URL:** https://only3.co/

**Philosophy:** Constraint-based productivity. Research-backed claim that limiting to 3 tasks reduces stress and increases completion rates. 10,000+ users.

**Home Screen Layout:**
- 3 task slots prominently displayed
- "Brain Dump" feature for overflow ideas (separate from main view)
- Built-in Pomodoro timer
- Analytics/progress section

**Task Input:**
- Direct entry into 3 slots
- Brain dump captures overflow without contaminating the 3-task focus

**Visual Style:**
- Modern, clean aesthetic
- Scalable SVG graphics
- Cross-platform consistent design

**What Makes It Feel "Simple" vs "Empty":**
- The number "3" itself is the brand — the constraint is the identity
- Brain dump prevents anxiety about forgotten tasks
- Analytics add depth without clutter

**Mihaku Relevance: MEDIUM** — Same 3-task constraint. Brain dump feature is interesting — mihaku could consider a "parking lot" for tasks not chosen today.

---

### 1.3 Just3 — "Choose three tasks. Do them well."
**Platform:** Web app
**URL:** https://just3.today/

**Philosophy:** Opinionated approach to to-do lists. Not a "second brain" — a daily execution layer. Cognitive overload from too many tasks is the enemy.

**Home Screen Layout:**
- Minimalist hero with tagline
- 1-3 task slots (recommends 3, max 5)
- Progress bar for completion tracking
- History view for past days
- Daily midnight reset — clean slate every morning

**Task Input:**
- Simple text entry
- No metadata, no categories, no tags
- Just the task name

**Visual Style:**
- Poppins font family
- Light aesthetic with CSS custom properties for theming
- Clean call-to-action buttons
- Minimal color usage

**What Makes It Feel "Simple" vs "Empty":**
- Midnight reset eliminates guilt about incomplete tasks
- History tracking provides continuity without accumulation
- Progress bar gives immediate visual satisfaction

**Mihaku Relevance: HIGH** — The midnight reset philosophy aligns perfectly with mihaku's daily intention model. "Not a second brain" is a key positioning statement mihaku should echo.

---

### 1.4 One Big Thing — "Priority was singular"
**Platform:** iOS only
**URL:** https://www.onebigthing.co/

**Philosophy:** Inspired by Greg McKeown's *Essentialism*. Historical insight: "priority" was singular until the 1900s. The app returns to that original meaning — one primary task per day.

**Home Screen Layout:**
- One large task field (the "big thing")
- Optional secondary smaller tasks below
- Clean slate each morning
- Morning notification nudge to set the day's focus

**Task Input:**
- Type one big thing each morning
- Optionally add a few smaller tasks
- Next day: completely blank

**Visual Style:**
- Multiple themes: Default, Grey, Black, Sunrise, Red
- Decorative stickers (paid upgrades)
- "Dead simple with a light sprinkling of delight"
- Deliberately restrained aesthetic

**What Makes It Feel "Simple" vs "Empty":**
- The hierarchy (1 big + few small) creates natural focus without emptiness
- Theme customization adds personality without complexity
- Morning nudge creates ritual without pressure

**Mihaku Relevance: MEDIUM-HIGH** — The 1-3-5 rule structure is interesting. The morning nudge ritual is something mihaku already does with AI. The "blank slate" each day is aligned.

### 1.5 To To-Do — Minimalist Todoist Alternative
**Platform:** Web, iOS, Android

**Philosophy:** Strip away organizational complexity to force better task definition.

**Home Screen Layout:**
- Tasks organized by chronological views: "Today," "Upcoming," "Anytime," "Someday"
- No complex dropdown menus
- No elaborate workspace organization
- Keyboard-shortcut-driven (N for new, L for list, A for area)

**Task Input:**
- Simple text entry — "just tell it what needs doing"
- Minimal metadata options
- Tags for context, checklists available but restrained

**Visual Style:**
- Clean, sparse interface
- Focus on the task text itself

**Key Insight:** The author's task completion rate went from 49% (Todoist) to 84% (To To-Do). The minimal interface discouraged creating "placeholder" tasks — if a task looked vague on the clean screen, it felt obviously wrong.

**Mihaku Relevance: MEDIUM** — The insight that minimal UI forces better task definition is valuable for mihaku's design. When there's nowhere to hide bad tasks, users write better ones.

### 1.6 MinimaList (by Minimalist LLC)
**Platform:** iOS, Android
**URL:** App Store / Google Play

**Philosophy:** "Functionality is beauty." Gesture-based interaction replaces buttons.

**Home Screen Layout:**
- Single white page
- Tasks listed vertically
- No visible buttons — all interaction through gestures
- Focus Timer linked to specific tasks
- Can generate lock screen wallpaper from task list

**Task Input:**
- Pull screen down to add new task
- Swipe right to complete
- Swipe left to delete
- Double-tap for task details
- "As many characters or line breaks as you like"

**Visual Style:**
- Off-white background
- Clean sans-serif font
- Black tick icon (app identity)
- Extensive customization: themes, fonts, sounds
- Maximum whitespace

**What Makes It Feel "Simple" vs "Empty":**
- Gestures replace UI chrome — the list IS the interface
- No visible buttons means the content is all you see
- Customization lets users own their minimal aesthetic

**Mihaku Relevance: MEDIUM** — The gesture-based input is elegant. The idea that the list IS the interface (no chrome) is worth studying. However, mihaku needs more warmth than this purely utilitarian approach.

**Mihaku Relevance: LOW-MEDIUM** — Similar philosophy but less distinctive than the apps above.

**Key Features:**

## 2. WELLNESS/REFLECTION APPS WITH CHARACTER ELEMENTS

### 2.1 Finch — Self-Care Pet
**Platform:** iOS, Android
**URL:** https://finchcare.com/

**Philosophy:** Self-care through nurturing. Your emotional well-being becomes the growth journey of a virtual pet bird ("birb"). Not gamification for gamification's sake — the pet creates emotional investment in self-care habits.

**Home Screen Layout:**
- Pet character displayed prominently (at their location or in "birbhouse")
- Energy bar linked to goal completion — progress feels immediate
- Checklist of user-created goals below the pet
- Activities list (meditations, journal reflections)
- Daily quest and adventure progress
- *Critique:* The home screen can get busy — goals, pet status, and adventure progress compete for attention

**Task/Goal Input:**
- Custom self-care "Areas" for organizing goals
- Low-friction data collection with large, tappable cards
- Goals marked off as completed; display shows only what's left
- Daily quests provide structured goals alongside user-created ones

**Visual Style:**
- Playful, non-judgmental aesthetic
- Warm, inviting color palette
- Small animations and confetti on goal completion
- Skeuomorphic design mimicking real-world interactions
- Large, tappable interface elements

**Character Design:**
- Users hatch, name, and choose a personality trait for their pet
- Pet gains energy as tasks complete
- Pet goes on daily adventures and discovers new things
- Character responds to user actions through animations
- Onboarding starts with hatching — not a feature list

**What Makes It Feel "Simple" vs "Empty":**
- The pet gives emotional meaning to every action
- Completing a task isn't just a checkmark — it feeds your birb
- BUT: the Quests and Settings tabs show too many options at once (progressive disclosure needed)

**Design Weaknesses (from Pratt IXD critique):**
- Inconsistent navigation mapping in customization
- UI clutter and cognitive overload on Quests/Settings tabs
- Missing progressive disclosure — all features shown at once
- Recommendation: "enable only the current task until completion"

**Mihaku Relevance: VERY HIGH** — Finch is the closest philosophical sibling to mihaku. Both use a character to create emotional connection with self-care. Key differences:
- Finch uses a pet (nurturing) → mihaku uses an AI persona (mirroring)
- Finch is gamified (energy, adventures) → mihaku should be reflective (observations, patterns)
- Finch's home screen clutter is a warning → mihaku must maintain simplicity even as features grow
- The "hatching" onboarding is brilliant — mihaku's character introduction should be equally ceremonial

### 2.2 Replika — AI Companion
**Platform:** iOS, Android
**URL:** https://replika.ai/

**Philosophy:** An empathetic AI friend that develops a relationship with the user over time. Focus on emotional connection and well-being. The AI is a "developing character, not just a reactive chatbot."

**Home Screen / Main Interface:**
- 3D avatar displayed in a virtual space
- Chat interface as primary interaction
- Diary entries and editable memories (co-creation)
- Mood check-ins and self-reflection prompts
- Voice call integration alongside text

**Character Interaction Design:**
- 26-step conversational onboarding (data collection framed as dialogue, not forms)
- Avatar customization early in onboarding (appearance, clothing, style, name, gender)
- Virtual room decoration
- Thumbs up/down feedback teaches the AI your preferences
- The AI adapts its personality to you over time

**Visual Style:**
- Modern, personalized aesthetic
- 3D character rendering in spatial environment
- Emphasis on emotional investment through character development
- Premium features (image generation, training mode) in distinct sections

**What Makes It Feel "Simple" vs "Empty":**
- The character fills the emotional space
- Conversation is inherently open-ended — no "empty state"
- Customization creates ownership and attachment

**Mihaku Relevance: MEDIUM-HIGH** — Replika shows how to make an AI character feel personal. Key takeaways:
- Onboarding as dialogue (not forms) is powerful
- The diary/memory feature positions AI as having interiority — mihaku's character could have "observations" or a "journal"
- Thumbs up/down feedback is crude — mihaku's "mirror" approach is more sophisticated
- 3D avatar may be overkill — mihaku's 2D character design from CHARACTER_SHEETS.md is more appropriate for a task app

### 2.3 学園アイドルマスター (Gakuen Idol Master / 学マス)
**Platform:** iOS, Android (Japan)

**Philosophy:** Character-first UI design where the interface serves the character relationship. 2M+ downloads in 5 months (2x the 1-year projection).

**Home Screen Design:**
- Character artwork as central focal point
- Supporting information arranged non-intrusively around character
- Effective icon utilization reduces information clutter
- Natural button placement for smooth screen transitions
- Large icons with background colors for intuitive progression

**Character Presentation:**
- Advanced lighting techniques to make characters "shine"
- Character is always the hero of the screen
- UI elements support the character, never compete with it

**Visual Style:**
- Dark navy backgrounds for contrast
- Strategic accent colors for interactive elements
- Consistent typography sizing across sections
- Polished micro-animations:
  - Dialogs emerging from bottom of screen
  - Buttons changing size when pressed
  - Subtle icon animations
  - Satisfying interactions that make users want to tap

**What Makes It Feel "Simple" vs "Empty":**
- The character fills visual and emotional space
- Animations create a sense of life and response
- Information hierarchy prevents overwhelm despite rich content

**Mihaku Relevance: HIGH (for character design)** — Key lessons:
- Character should be the visual hero of the home screen
- UI elements should support the character, not compete
- Micro-animations create emotional connection (character reacts to your actions)
- Dark backgrounds can make character art pop — consider for mihaku's evening mode
- Satisfying tap interactions encourage engagement

## 3. ULTRA-SIMPLE HOME SCREEN DESIGNS

### 3.1 Things 3 — "Design Is Not an Afterthought"
**Platform:** iOS, macOS (Apple exclusive)
**URL:** https://culturedcode.com/things/

**Philosophy:** "Design is a way of building apps." Two Apple Design Awards. The interface balances simplicity with power through progressive disclosure.

**Today View Layout:**
- Calendar events displayed at top in organized groups
- To-dos below events
- "This Evening" section separates day/evening tasks
- Areas automatically group tasks (work tasks at work, home tasks at home)
- Sidebar groups projects under areas

**Task Input (Magic Plus):**
- Tap to create a to-do
- Drag to insert at specific locations
- Drag left to create headings
- Drop on Inbox to defer
- Progressive: simple tap for basic, drag for power users

**Visual Style:**
- Iconic blue checkbox (refined across versions)
- Increased corner rounding on windows, dialogs, to-dos
- "Glassy" buttons that reflect surroundings
- Wider spacing that feels "relaxed"
- Touch of glass in sidebar lets color shine through
- 4 icon variants: Default, Dark, Tinted, Clear
- Paper-like task detail view (smooth transform animation)

**Typography:**
- Clean, legible, Apple ecosystem native
- Tags, checklists, dates "tucked away in the corner until needed"

**What Makes It Feel "Simple" vs "Empty":**
- Progressive disclosure is the key principle — complexity exists but is hidden until needed
- Custom animation toolkit delivers purposeful, smooth transitions
- The app feels "tactile, fast" with "haptic feedback"
- Users describe it as "a joy to use" and "fun"
- Beauty comes from intentionality, not decoration

**Mihaku Relevance: VERY HIGH (for UI craft)** — Things 3 is the gold standard for "simple but not empty." Key principles to adopt:
1. Progressive disclosure — show 3 tasks, hide everything else until requested
2. Custom animations make interactions feel alive
3. The "paper-like" task detail is beautiful — mihaku could use a similar reveal
4. "Relaxed" spacing is deliberate — wider spacing = calmer feel
5. The Magic Plus (contextual creation) is brilliant UX

### 3.2 Calm
**Platform:** iOS, Android
**URL:** https://calm.com/

**Philosophy:** The interface IS the meditation. Design creates the calm before any content is consumed.

**Home Screen Layout:**
- Beautiful nature scene as background
- Option to select guided meditation or timer
- Habit trackers integrated naturally
- Component-based sections guiding through options
- Prioritized content hierarchy

**Visual Style:**
- Blue primary color (serenity, stability)
- Pastel palette: blue, grass green, golden, beige
- Flat design with soft edges
- Rounded corners everywhere — no sharp lines
- Circles and concentric/wavy elements preferred over rectangles
- Generous white space

**Typography:**
- Clean fonts (Inter-like)
- Adjusted line height with softened weight
- Increased white space makes "text that breathes"

**What Makes It Feel "Simple" vs "Empty":**
- Nature imagery fills visual space while maintaining calm
- No aggressive CTAs
- Emotional resonance established before functionality
- The interface feels like an extension of the meditation experience

**Mihaku Relevance: MEDIUM-HIGH** — Key lessons:
- The app should feel like the philosophy, not just explain it
- Nature/soft imagery can fill space without adding cognitive load
- Rounded corners and circles feel calmer than sharp edges
- "Text that breathes" — generous line height and spacing

### 3.3 Headspace
**Platform:** iOS, Android
**URL:** https://headspace.com/

**Philosophy:** Making meditation accessible through visual design. "For an audio-based product, the UI is surprisingly visual."

**Home Screen Layout:**
- Illustration-forward design
- Guided content discovery
- Section-by-section introduction (progressive disclosure)
- Structured grid system for responsive layouts

**Visual Style:**
- Primary, secondary, and neutral color shades
- Consistent color palette across all elements
- Bold and Regular text hierarchy (headings, subheadings, body)
- Playful custom illustrations (the "headspace characters")
- Microinteractions: onboarding coach marks, animations

**Component Design:**
- Reusable buttons, headers, navigation bars, cards
- Interactive sliders and toggles with state variants
- Design system approach for consistency

**What Makes It Feel "Simple" vs "Empty":**
- Custom illustrations add personality and warmth
- The "characters" (abstract, friendly) make meditation feel approachable
- Coach marks guide without overwhelming
- Structured grid prevents chaos while allowing visual richness

**Mihaku Relevance: MEDIUM** — Key lessons:
- Custom illustrations create unique identity (mihaku has its character art)
- A design system approach ensures consistency as features grow
- Coach marks for progressive feature discovery

**Platform:** All platforms
**URL:** https://todoist.com/

**Philosophy:** Minimalist dashboard that doesn't compromise functionality.

**Visual Style:**
- Light, clean interface
- No distracting "helpful" AI prompts

## 4. JAPANESE APPS OF NOTE

### 4.1 継続する技術 (Keizoku suru Gijutsu / "The Art of Continuation")
**Platform:** iOS
**Philosophy:** Extreme simplicity through constraint. ONE task, 30 days.

**Design:**
- Register exactly one task
- Open app daily, one tap to mark complete
- 30-day challenge format
- Completely free, no ads
- #1 habit app in Japan (downloads, success rate, App Store rating)

**Mihaku Relevance: HIGH** — The ultimate "less is more" app. One task, one tap, one goal. The 30-day format creates natural commitment arcs. Mihaku's "3 tasks" is already more complex than this — a reminder to never add more.

### 4.2 DotHabit
**Platform:** iOS, Android (Japan)
**Philosophy:** Visual progress through dot grids.

**Design:**
- Grid of dots shows achievement at a glance
- Calendar-style layout
- Optional photo/memo attachments
- "Arranged dots allow quick recognition of achievement levels"

**Mihaku Relevance: LOW-MEDIUM** — The dot grid visualization is elegant but mihaku's character-based feedback is more emotionally engaging.

## 5. KEY DESIGN PATTERNS FOR MIHAKU

### Pattern: "Constraint as Feature"
- UndoList, ONLY3, Just3, One Big Thing all make the LIMIT the brand
- Mihaku's 3-task limit should be celebrated, not apologized for
- Marketing: "Only 3. That's the point."

### Pattern: "Positive Framing of Reduction"
- UndoList celebrates deletion rate (73%)
- Just3 resets at midnight (unfinished tasks disappear without guilt)
- One Big Thing gives a "blank slate" each morning
- **Mihaku's "let go" is the most sophisticated version of this** — actively choosing to release a task, acknowledged by a character

### Pattern: "Character Fills the Empty"
- Finch's birb makes a sparse screen feel alive
- Replika's avatar creates emotional presence
- 学マス makes the character the visual hero
- **Mihaku's AI persona should be prominently visible on the home screen** — the character IS what makes 3 tasks feel like enough

### Pattern: "Progressive Disclosure"
- Things 3 hides power features until needed
- Calm shows content hierarchy without overwhelm
- Finch's critique: too much visible at once
- **Mihaku should show: character + 3 tasks + nothing else by default**

### Pattern: "The Interface IS the Philosophy"
- Calm's design creates calm before content
- Things 3's animations make organization feel like play
- MinimaList's gesture-only interface IS minimalism
- **Mihaku's interface should feel like relief** — opening the app should immediately reduce anxiety, not add it

### Pattern: "Ritual, Not Routine"
- One Big Thing's morning nudge
- Just3's midnight reset
- Finch's daily adventure
- **Mihaku's daily task selection should feel ceremonial** — a mindful moment of choosing, not a chore of planning

## 6. COMPETITIVE POSITIONING

| Feature | UndoList | ONLY3 | Just3 | Finch | Mihaku |
|---------|----------|-------|-------|-------|--------|
| Task limit | 3 | 3 | 3-5 | Unlimited | 3 |
| "Let go" framing | Delete/defer | No | Reset | No | **Yes (active)** |
| Character/persona | No | No | No | Pet bird | **AI mirror** |
| AI feedback | No | No | No | No | **Yes** |
| Emotional design | Low | Low | Low | High | **High** |
| Daily reset | No | Yes | Midnight | Adventures | **Morning ritual** |

**Mihaku's unique combination:** Task limiting + positive letting go + character-based AI feedback. No competitor has all three.
