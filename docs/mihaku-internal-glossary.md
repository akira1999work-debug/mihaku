# mihaku 内部用語集

> 開発チーム向け。外部仕様書には載せない内輪の設計用語。

## キャラクター類型

| キャラ | 内部呼称 | 意味 | 外向け表現 |
|---|---|---|---|
| 理央 | お姉さんの提案者 | しっかり者のお姉さん。構造化+ワクワクする代替案 | 頼れるお姉さん |
| 悠真 | 包容力の安心役 | 5人で一番「大人」。温かい冷静さ | 穏やかな安心役 |
| 心春 | 癒しの本音引き出し | 気の置けない女友達。問いかけで核心を突く | 温かい本音引き出し役 |
| 陽斗 | ムードメーカー | ユーザーに一番近い存在。正直で直球 | 正直なムードメーカー |
| 凛 | **クーデレの反論者** | クール+デレ。普段はクールだが素が漏れる。デビルズアドボケイト | 鋭い反論者 |

## クーデレとは

「クール」+「デレ」の造語。普段はクールで感情を見せないが、特定の相手や状況で素の感情が漏れるキャラクター類型。凛の核心はここにある:
- 普段: 鋭い反論、短い言葉、感情を見せない
- 素が出る時: 照れ隠し、不器用な気遣い、認めるところは認める（「...正しい判断。」）
- Level 3到達時: 「ちょっとだけ、すごいと思った」（禁止ワード破り）

## 距離感Phase

| Phase | 内部名 | 期間 | 特徴 |
|---|---|---|---|
| Phase 1 | 丁寧期 | 累計1-5日 | 敬語ではないが節度。タメ口なし |
| Phase 2 | 打ち解け期 | 累計6-15日 | 柔らかくなるがまだ丁寧ベース |
| Phase 3 | ここぞ期 | 累計15日+ | 普段は礼節。ここぞでタメ口が出る |

## エンドコンテンツ

学園アイドルマスター（学マス）の設計に着想を得た、キャラへの愛着を深める仕組み:
- 関係性Level（1→2→3）
- キャラの弱さ・過去の解放
- 禁止ワード破り（各キャラ1回限り）
- 兄妹関係の解放（心春×陽斗）
- 「気づく人だけ気づく」変化

## AI生成の内部用語

| 用語 | 意味 |
|---|---|
| 2段階生成 | 凛の反論を他4人の発言をインプットにして別プロンプトで生成する方式 |
| B+C方式 | ビジョンを聞かずに育てる。行動観察（C）+ 会議中の問いかけ（B）でユーザーの価値観を蓄積 |
| 光転 | 幸福の科学由来。逆境をポジティブにリフレーミングする考え方。dailyWordsの`reframe`カテゴリ |
| 情報可変方式 | ユーザーの入力量に応じて5人の振る舞いを変える。情報少=問いかけ中心、情報多=視点の提示 |

## 廃止した用語・機能

| 対象 | 理由 |
|---|---|
| パーソナリティ（standard/yuru/maji） | 5人のキャラが口調のバリエーション。上位切り替え不要 |
| ケアモード | 0個の日は何も起きないのが正解 |
| 「今日は休む」ボタン | 3つしかないのに一括操作は過剰 |
| 「明日に回す」ボタン | 先延ばしの正当化装置 |
| AITAS（旧称） | タスク概念を廃止したため改名 → mihaku |
